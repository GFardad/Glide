## Knowledge graph integration

Trace and program views can now consume the local `graphify-out/graph.json` through `packages/tracer/src/graphify.ts`. The `GraphifyClient` supports BFS/DFS queries, shortest-path discovery between concepts, community enumeration, per-node detail lookups, and a deterministic PR-impact estimator. These capabilities are exposed over MCP via `glide_graph`, making graph-backed reasoning available to downstream agents without changing Graphify's output path conventions.
